# IMPACT-BRIDGE

> **Centralized NGO Management & Impact Tracking Platform**
> 
> *A web-based platform designed to streamline NGO operations by managing volunteers, beneficiaries, donations, programs, interactive GIS impact maps, and real-time reports in one integrated system.*

---

## 🌟 Key Features

### 🌍 Public Portal
- **Interactive Landing & Showcase:** Highlight active programs, community metrics, and success stories.
- **Programs & Causes:** Detailed program overview with funding goals and progress tracking.
- **Interactive Impact Map:** GIS-powered interactive map visualizing ongoing initiatives, relief centers, and community outreach points.
- **Online Donations & Pledges:** Seamless donation portal with multiple payment methods, preset amounts, and live celebration feedback.
- **Volunteer Registration:** Streamlined onboarding for volunteers to join active causes.

### 🛡️ Admin & Operational Hub
- **Executive Dashboard:** Live analytical charts for donations, volunteer contributions, and active campaigns.
- **Program & Campaign Management:** Create, edit, track, and manage active NGO initiatives.
- **Beneficiary Directory:** Track beneficiary records, support history, and allocation statuses.
- **Volunteer Management:** Manage volunteer roster, assignment states, and contact channels.
- **Financial & Donation Analytics:** Real-time metrics, donor history, and exportable reports.
- **Customizable NGO Settings:** Organization profile, currency preferences, and theme configurations.

---

## 🛠️ Tech Stack

- **Frontend Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Mapping & GIS:** [Leaflet](https://leafletjs.com/) & [React-Leaflet](https://react-leaflet.js.org/)
- **Icons & Visuals:** [Lucide React](https://lucide.dev/) & Canvas Confetti
- **Styling:** Modern Responsive CSS Design System

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/YAth-f4/IMPACT-BRIDGE.git

# Navigate into the project folder
cd IMPACT-BRIDGE

# Install dependencies
npm install
```

### 3. Running Locally
```bash
# Start the development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
